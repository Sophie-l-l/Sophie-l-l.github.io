A modern, dark-themed personal portfolio website showcasing software engineering projects, technical skills, and professional experience. Built with vanilla HTML/CSS/JavaScript — no frameworks.

**Live Site:** [https://sophie-l-l.github.io/](https://sophie-l-l.github.io/)

---

## Features

- **Dark terminal-inspired design** — Professional dark theme with cyan/green accent colors and JetBrains Mono typography
- **Smooth scroll navigation** — Single-page layout with animated section transitions
- **Scroll progress indicator** — Visual progress bar showing page position
- **Parallax effects** — Subtle background movement on scroll for depth
- **Typewriter animation** — Dynamic text cycling on the hero section
- **Responsive navbar** — Sticky navigation with scroll-triggered background changes
- **Project showcase** — Grid layout highlighting key projects with descriptions and links
- **Skills section** — Categorized technical skills with visual presentation
- **Experience timeline** — Professional and academic experience
- **Contact section** — Social links (GitHub, LinkedIn, Email)

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Structure** | HTML5 (single-page, semantic) |
| **Styling** | CSS3 (custom properties, Grid, Flexbox, glassmorphism) |
| **Typography** | Google Fonts (JetBrains Mono, Inter) |
| **Interactivity** | Vanilla JavaScript (scroll events, typewriter, parallax) |
| **Deployment** | GitHub Pages |

## Sections

| Section | Content |

| **Projects** | Featured project cards with links |
| **Skills** | Technical skills by category |
| **Experience** | Work and academic timeline |
| **Contact** | GitHub, LinkedIn, email links |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Sophie-l-l/Sophie-l-l.github.io.git
cd Sophie-l-l.github.io

# Open in browser (no build step required)
open index.html
```

No dependencies — single HTML file with inline CSS and JavaScript.
